# TaskList

[Español](README.es.md)

Angular practice project created for Argentina Programa. It explores components, task state and HTTP communication with a local JSON server.

## Stack

Angular · TypeScript · JSON Server.

## Scope and configuration

Run npm run server in a separate terminal for the db.json API on port 5001. This is a learning exercise, not a production task service.

## Local development

Use a Node.js toolchain compatible with package.json and the dependency lockfile, when present.

```sh
npm install
npm start
npm run build
npm test
```
