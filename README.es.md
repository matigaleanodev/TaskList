# TaskList

[English](README.md)

Proyecto de práctica Angular creado para Argentina Programa. Explora componentes, estado de tareas y comunicación HTTP con un servidor JSON local.

## Stack

Angular · TypeScript · JSON Server.

## Alcance y configuración

Ejecutar npm run server en otra terminal para la API de db.json en el puerto 5001. Es un ejercicio de aprendizaje, no un servicio de tareas para producción.

## Desarrollo local

Usar un entorno Node.js compatible con package.json y el lockfile de dependencias, cuando exista.

```sh
npm install
npm start
npm run build
npm test
```
